# AtlasCorr AI — Portfolio Analytics Specification

Portfolio Analytics ranks products across corridors.

## Inputs
- Multiple HS codes  
- Multiple corridors  
- Dossier outputs  

## Scoring Dimensions
- Duty burden  
- Compliance complexity  
- Logistics stability  
- Cost exposure  
- Risk flags  
- Export readiness  

## Outputs
- Ranked product list  
- Corridor suitability  
- Opportunity map
