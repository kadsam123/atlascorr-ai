# AtlasCorr AI — API Documentation

## Base URL
`/api/`

## Endpoints
### POST /api/hs-code
Classify product description into HS Code.

### POST /api/tariff
Compute duty rates.

### POST /api/compliance
Generate document compliance checklists.

### POST /api/route-score
Evaluate shipping logistics transits.

### POST /api/export-plan
Generate export plan instructions.

### POST /api/dossier-batch
Generate multi-corridor dossiers.

### POST /api/portfolio-analytics
Run portfolio analytics.

## Response Format
All responses follow:
- deterministic core  
- enrichment  
- qa_supervisor logs
