# AtlasCorr AI — Dossier Engine Specification

The Dossier Engine aggregates agent outputs into a unified corridor dossier.

## Inputs
- HS code  
- Product name  
- Corridors  
- Cargo value  
- Mode  

## Process
1. Run all agents per corridor  
2. Collect deterministic cores  
3. Merge enrichment safely  
4. Apply QA governance  
5. Generate summary  
6. Generate strategy report  

## Outputs
- Dossier summary  
- QA reflections  
- Corridor comparison  
- Strategy report
