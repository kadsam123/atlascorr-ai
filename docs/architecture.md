# AtlasCorr AI — Architecture Overview

AtlasCorr AI is built around a multi-agent corridor intelligence pipeline.  
Each agent contributes a deterministic core and optional enrichment, governed by Antigravity QA.

## High-Level Flow
1. HS Agent → Classifies product  
2. Tariff Agent → Computes duties  
3. Compliance Agent → Documents + regulatory burden  
4. Route Agent → Logistics + cost + transit  
5. Export Plan Agent → Step-by-step workflow  
6. QA Supervisor → Validates consistency  
7. Dossier Engine → Aggregates corridor intelligence  
8. Portfolio Analytics → Ranks products  
9. Strategy Engine → Generates narrative reports  

## Deterministic Core
Each agent guarantees:
- Valid schema  
- Minimal safe output  
- No contradictions  
- No missing critical fields  

## Hybrid Enrichment
Adds:
- Tariff fluctuations  
- Congestion  
- Seasonal effects  
- Document variations  
- Logistics volatility  

## QA Governance
Antigravity ensures:
- No contradictory enrichment  
- No missing fields  
- No unsafe recommendations  
- No broken schemas
